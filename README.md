# ✂️ Photo Cropper

Простое веб-приложение для обрезки фотографий прямо в браузере. Никаких серверов, регистраций и загрузок куда-либо — вся работа происходит локально.

![screenshot](screenshot.png)

## Возможности

- 🖼 **Загрузка изображения** — файлом, drag & drop или из буфера обмена (`Ctrl+V`)
- 📐 **Соотношение сторон** — свободный режим или фиксированное (`16:9`, `1:1`, `4:3`, …), ввод вручную
- 🎚 **Настройка качества** — от 10% до 100% (для JPEG и WebP)
- 💾 **Форматы сохранения** — JPEG, PNG, WebP
- 📏 **Ограничение размера** — максимальная ширина итогового файла в пикселях
- 📝 **Своё имя файла** — с автоматической подстановкой расширения
- 📊 **Индикатор размера** — показывает разрешение и вес готового файла
- 🌐 **Работает офлайн** — весь код и логика на клиенте
