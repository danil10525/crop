✂️ Photo Cropper

Обрезка фото для сайта — прямо в браузере, без загрузки на сервер

1. Изображение

Перетащите файл сюда, вставьте из буфера (Ctrl+V) или используйте кнопки ниже.

Файл не отправляется на сервер — всё работает локально.

2. Параметры обрезки

Форматы: 16:9, 1.5 или 3/2. Enter — применить.

3. Параметры сохранения

Качество влияет только на JPEG и WebP. PNG сохраняется без потерь.

4. Выделите область и обрежьте
